# نصب و راه‌اندازی OMEGA (فارسی)

پنل **OMEGA** بر پایه‌ی **3x-ui نسخه ۳.۳.۱** است و علاوه بر برندینگ OMEGA، قابلیت‌های نمایندگی، AmneziaWG native، OpenVPN و L2TP/IPsec را اضافه می‌کند.
نام سرویس (`x-ui`) و مسیرهای اصلی (`/usr/local/x-ui`، `/etc/x-ui`) با upstream سازگار مانده‌اند، اما نسخه‌ی release خود OMEGA جداگانه مدیریت می‌شود.
قابلیت‌های جدید فقط ظاهری نیستند و status، traffic، quota، چرخه‌ی کلاینت، reseller و recovery را نیز پوشش می‌دهند.

---

## ۱) نصب سریع (تک‌دستوری)

روی سرور (اوبونتو/دبیان/آرچ/الپاین/راکی/سن‌اواس …) با کاربر **root**:

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/Dark-Sky07/OMEGA/main/install-omega.sh)
```

این لینک همیشه جدیدترین release OMEGA را پیدا می‌کند و فایل‌های همان release را نصب می‌کند؛ tag قدیمی یا مخزن vanilla 3x-ui fallback نیست.

اسکریپت خودش این کارها را می‌کند:

1. نصب پیش‌نیازها (curl/tar/socat/openssl و …)
2. دانلود پکیج آماده‌ی معماری سرور از ریلیز OMEGA (شامل Xray-core، geoip/geosite، mtg)
3. نصب در `/usr/local/x-ui` و ساخت سرویس systemd با نام `x-ui`
4. پیش‌نیازهای OpenVPN و L2TP/IPsec شامل `openvpn`، `strongswan`، `xl2tpd`، `ppp`، `iptables` و `iproute2` را نصب و دستگاه‌های TUN/PPP را بررسی می‌کند
5. اگر نصب قبلی وجود داشته باشد، **تنظیمات و دیتابیس حفظ می‌شود**
6. راه‌اندازی مجدد پنل + نمایش آدرس ورود

در پایان: پورت پیش‌فرض `2053`، یوزر/پس `admin/admin` (از داخل پنل حتماً عوض کنید) و مسیر مخفی ورود هم قابل تنظیم است.

## ۲) مدیریت روزمره

```bash
x-ui            # منوی مدیریت (شروع/توقف/ری‌استارت/تنظیمات/لاگ/آپدیت/حذف)
x-ui status     # وضعیت سرویس
x-ui settings   # نمایش تنظیمات فعلی و مسیر مخفی
x-ui log        # لاگ‌ها
x-ui update     # آپدیت به آخرین نسخه‌ی OMEGA (از همین ریپو؛ پنل جایگزین نسخه‌ی اصلی 3x-ui نمی‌شود)
x-ui uninstall  # حذف کامل
```

## ۳) بعد از نصب: ساخت اولین نمایندگی

1. با ادمین وارد پنل شوید → از منو **نمایندگی‌ها** را باز کنید.
2. **نمایندگی جدید**: یوزر/پس، نام، سقف ترافیک (GB)، سقف تعداد کلاینت، سقف تعداد ورودی، قیمت هر گیگابایت و شارژ اولیه.
3. با آیکون «ورودی‌ها» مشخص کنید کدام ورودی‌ها مال این نماینده باشد (کلاینت‌های آن ورودی‌ها خودکار در اختیارش می‌آیند).
   با آیکون «واگذاری کلاینت» می‌توانید کلاینت‌های تک‌نفره (روی ورودی‌های مشترک) را هم بدهید.
4. با «موجودی» شارژ/برداشت ثبت کنید و با «گزارش» مصرف، هزینه و دفتر حساب را ببینید.

نماینده با همان یوزر/پسی که ساختید در **همان صفحه‌ی ورود پنل** لاگین می‌کند و فقط دو صفحه می‌بیند:
**گزارش فروش** و **پروفایل**، به‌همراه ورودی‌ها/کلاینت‌های خودش. دسترسی او به بقیه‌ی APIها با خطای 403 بسته است.

## ۴) استفاده از AmneziaWG

در فرم inbound نوع **AmneziaWG** را انتخاب کنید. OMEGA پارامترهای AWG 3.1، کلیدها، peerها، allowed IP، status، traffic و quota را مدیریت می‌کند و profile native می‌سازد.

برای اتصال اندروید:

1. از صفحه‌ی اطلاعات کلاینت، بخش **AmneziaWG** را باز کنید.
2. برای QR از گزینه‌ی QR همان بخش استفاده کنید یا فایل `.conf` را دانلود کنید.
3. در اپ مستقل AmneziaWG گزینه‌ی **Import from file or archive** را بزنید.

QR این بخش متن خام `[Interface]`/`[Peer]` است. لینک `vpn://` مربوط به AmneziaVPN است و نباید داخل importer مستقل AmneziaWG وارد شود.

## ۵) نصب دستی (سروری که به گیت‌هاب دسترسی ندارد)

از صفحه‌ی ریلیزها، فایل `x-ui-linux-<arch>.tar.gz` معماری سرور را دانلود و روی سرور باز کنید:

```bash
tar zxvf x-ui-linux-amd64.tar.gz       # amd64 | arm64 | armv7 | armv6 | 386 | armv5 | s390x
cd x-ui && chmod +x x-ui bin/xray-linux-* && cp -f x-ui.service /etc/systemd/system/ 2>/dev/null \
  || cp -f x-ui.service.debian /etc/systemd/system/x-ui.service
cp -f x-ui.sh /usr/bin/x-ui && chmod +x /usr/bin/x-ui
./x-ui     # اجرای اولیه برای ساخت دیتابیس
systemctl daemon-reload && systemctl enable x-ui && systemctl start x-ui
```

## ۶) بروزرسانی و تمیزکاری

- آپدیت: `x-ui update`
- حذف: `x-ui uninstall` (دیتابیس در `/etc/x-ui` می‌ماند؛ قبل از حذف بکاپ بگیرید)
- بکاپ: در پنل از بخش تنظیمات → «بکاپ» یا کپی گرفتن از `/etc/x-ui/x-ui.db`

## ۷) نکته‌ی امنیتی

- پورت پیش‌فرض 2053 است؛ شماره‌ی پورت و مسیر مخفی ورود را عوض کنید.
- رمز ادمین و رمز هر نماینده را عوض کنید؛ در صورت لو رفتن رمز یک نماینده، از دکمه‌ی «بازنشانی رمز عبور» استفاده کنید
  (نشست‌های قبلی او فوراً باطل می‌شوند).
- اگر نماینده غیرفعال شود، ورودی‌های او هم خاموش می‌شوند؛ با فعال‌سازی مجدد، وضعیت ورودی‌ها خودکار برنمی‌گردد و باید دستی روشن کنید.
